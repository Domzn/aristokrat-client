# Aristokrat Roleplay · Client-Download

Hier liegt der **HogwartsMP-Client** zum Herunterladen für Spieler von [Aristokrat Roleplay](https://aristokrat.gg), dem deutschsprachigen Roleplay-Server für Hogwarts Legacy.

Der Client ist unverändert. Die Bereitstellung erfolgt mit Erlaubnis der HogwartsMP-Entwickler. HogwartsMP und alle zugehörigen Dateien sind Eigentum ihrer Entwickler. Weitere Informationen zum Client stehen unter [docs.hogwarts-mp.com](https://docs.hogwarts-mp.com).

## Download

Die Dateien findest du unter **Releases**. Den Inhalt gibt es in zwei Formaten:

| Datei | Hinweis |
|---|---|
| `HogwartsMP-Client-<Version>.zip` | Lässt sich unter Windows ohne Zusatzprogramm entpacken |
| `HogwartsMP-Client-<Version>.7z` | Kleiner, zum Entpacken brauchst du zum Beispiel 7-Zip |

## Einrichten

1. Du brauchst eine eigene Kopie von **Hogwarts Legacy für PC**.
2. Entpacke das Archiv in einen Ordner deiner Wahl, zum Beispiel `C:\Spiele\HogwartsMP-Client`.
3. Starte `HogwartsMPLauncher.exe`.
4. Wie du auf den Server kommst, erfährst du auf unserem Discord.

## Prüfsummen

Die SHA-256-Prüfsummen stehen bei jedem Release. So prüfst du sie in PowerShell:

```powershell
Get-FileHash .\HogwartsMP-Client-1.10.0.zip -Algorithm SHA256
```
